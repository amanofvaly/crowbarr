# Dashboard

Mode: Operate. A familiar administrative interface built with Bootstrap 5.3.8.
Use system typography, a light neutral workspace, restrained green primary actions,
and Bootstrap's semantic status colors with visible text labels. The first viewport
prioritizes jobs and their state; configuration occupies a separate settings view.

Use native forms, persistent labels, readable error messages, keyboard focus, and
responsive layouts. Do not introduce charts, decorative metrics, illustrations,
invented jobs, or custom component systems. Bootstrap assets are served locally.
