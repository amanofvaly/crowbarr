    Settings

    Connect once. Crowbarr watches for new media and subtitle changes.

    Media managers

    Sonarr and Radarr supply the library: imported files, monitoring preferences, and upgrades. With either connected, only files in their catalogs are processed.

    Map paths if the containers see different folders. Save before testing. Leave a saved key blank to keep it; clear the URL to disconnect. Bazarr checks and Plex refreshes are optional.

    Media folders

    These folders authorize media access. Without Sonarr or Radarr, Crowbarr discovers videos by scanning them directly.

    One absolute folder per line. Paths already defined by a Sonarr/Radarr mapping need not be repeated. Crowbarr needs permission to write subtitles beside each video.

    If no authored subtitle arrives within this window, Crowbarr checks embedded subtitles, then transcribes. A later download starts a new job.

    Speech processing

    One file at a time. English audio and subtitles are supported in this first release.

    GPU processing needs the CUDA image and NVIDIA container support. Smaller models trade recognition accuracy for lower resource use.

    Import events

    Optional hooks make discovery faster. Scheduled checks cover missed events automatically.

    In Sonarr or Radarr, add a Webhook connection for imports, upgrades, renames, and deletions.

    Use a Crowbarr address reachable from that service:

    http://crowbarr:8449/api/hooks/sonarrhttp://crowbarr:8449/api/hooks/radarr

    Username: crowbarr. Password: your Crowbarr API key. Events trigger a fresh API sync; scheduled syncs cover missed events. Bazarr downloads are discovered beside the imported media.
